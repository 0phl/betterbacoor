# Better LGU license review — September 17, 2026

Source: [BetterLGU directory](https://lgu.bettergov.ph/). Directory names and links are attributed to the community under [CC BY 4.0](https://github.com/jmacj/better-lgu-directory/blob/main/LICENSE). Observations below are our review notes; they do not imply endorsement.

## Coverage and limits

Checked all 108 LGU rows in the deployed directory: 51 listed website URLs and 89 linked repository root LICENSE paths. Of the websites, 49 returned successful HTTP responses and two returned HTTP errors. Nineteen returned license or contribution wording; 30 did not expose it in the returned HTML, often because the page requires JavaScript. Those 30 are not classified as having no license. This is a homepage and root-license survey, not a rendered review of every page or a file-by-file legal audit.

Repository root license text contained: 48 CC0, 20 MIT plus CC BY 4.0, four MIT, one CC BY 4.0, and two AGPL. Fourteen requested root LICENSE paths were unreadable; a repository may use another filename or branch. These are observations of the linked repository/ref, not guarantees that its live site uses that code. The scan includes BetterBacoor's remote state before this local MIT policy change. The directory's displayed active-project counter was not used as the inventory size.

[Machine-readable observations](lgu-footer-licenses.json) preserve checked URLs, response statuses, short HTML excerpts, and per-repository findings. For MIT and CC BY wording, license scope must still be read: BetterSolano explicitly assigns MIT to code and CC BY 4.0 to content. BetterCalauan's linked react-typescript LICENSE path returned 404, despite MIT/CC BY wording in the live footer; no license was inferred from that missing file.

## BetterBacoor decision

Local history shows the CC0 dedication originated in the initial commit, 878be29, and the recorded upstream snapshot is iyanski/betterlocalgov at b807a8bee0a005049e3d3492413d1ab03be7cfa1. The user's continuation of the transferred project does not invalidate that earlier public-domain dedication. MIT is being introduced for new original software contributions while earlier CC0 permissions, non-software content terms, third-party licenses and authorship are preserved. See [the licensing policy](../LICENSING.md).
